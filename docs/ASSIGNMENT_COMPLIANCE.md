# Соответствие заданию №1

Текст преподавательского задания отдельно не предоставлен; матрица следует требованиям пользователя и явно указанному расхождению по SQL. Неизвестные требования преподавателя не считаются автоматически выполненными.

| Требование | Реализация / статус |
|---|---|
| Самостоятельный C# CLI | Новый solution из пяти проектов, русские меню, UTF-8, без WPF |
| Максимальный reuse | Core/Data побайтно; Windows-адаптеры только namespace; SOURCE_REUSE и SHA-256 manifest |
| .NET 9 / EF | Сохранены .NET 9 и пакеты 9.0.22, ORM/провайдер не заменены |
| SQL Server Express / общая БД | Прежний AppDbContext, SecureFileManagerDB, четыре таблицы, миграции без изменений; startup только чтение |
| PostgreSQL/MySQL/SQLite в списке преподавателя | **Расхождение: выбран SQL Server. Требуется подтверждение допустимости преподавателем. Автоматически не выполнено** |
| Регистрация/вход/пароли/lockout | Прежние сервисы и результаты, звёздочки/Backspace/Esc, обычные правила владельца |
| Общий StorageRoot | Существующая конфигурация, GUID пользователей, preflight; дубликаты при входе не создаются |
| Диски/каталоги | Прежние browser/drive services, свойства, таблица, навигация, поиск/сортировка |
| Внешние операции | Create/copy tree/move same-volume/rename/trash/restore; ACL/no overwrite/links ограничения сохранены |
| Личные файлы | Create/read/edit/import/delete, explicit sync/recovery; отсутствующие private copy/move/rename/trash не выдуманы |
| TXT/JSON/XML | Исходный валидатор, сервисный редактор, создание/просмотр/изменение/проверка/сохранение/отмена |
| YAML | Не добавлен, отсутствует в исходнике |
| ZIP | Исходный ZipEngine, preview/create/extract, Slip/Bomb/CRC/лимиты/отмена |
| Аудит | Прежние SQL Operations/JournalService, actor filters/pages; ошибки аудита блокируют файловые операции |
| Ввод/ошибки/отмена | Маскировка, подтверждения, /cancel, Ctrl+C для сервисного CancellationToken, dirty-buffer решения |
| Два процесса | Анализ механизмов/рисков в ARCHITECTURE; полная WPF+CLI конкурентная приёмка не выполнена |
| Тесты | Исходные service tests адаптированы без WPF, новые CLI tests; фактические результаты в TEST_REPORT |
| Git | Отдельный репозиторий CLI, исходный Git не изменён, коммита нет |

Не включены новая схема, миграция рабочих данных, демо-пользователи, новый SQL-провайдер, обход Windows ACL, глобальные роли и другие функции вне заданного этапа. Ручная приёмка и формальное подтверждение СУБД остаются открытыми.
